# GLIDER-01 設計書 v0.1（紙設計・初号グライダー）

2026-11-16／設計：シシア／製作：吉田（予定）
位置づけ：実験2＝設計メソッド棚の検証。要求定義から一機を通し、全体の設計プロセスを手順書v1に固定するための初号機。
方法：設計メソッド棚（PHAK／Naval Aviators の基礎式）＋ 実験1で検証済みのポーラ法（CD = CD0 + k·CL²、k = 1/(π·e·AR)）。

## 1. 要求定義（v0.1、シシア提案値）
- 形式：動力なしグライダー、RC 2チャンネル（ラダー＋エレベーター）
- 翼幅 1.50 m／全備重量 420 g 目標
- 狙い：空力予測と飛行実測の照合が最もきれいに取れる構成（動力変数を排除）
- 製作分担：主翼は3分割（輸送とプリンタ造形範囲の両立を狙う。具体寸法は吉田の造形環境に合わせて次版で確定）

## 2. 主要諸元（計算値）
| 項目 | 値 |
|---|---|
| 翼面積 S | 0.270 m²（翼幅1.50m × 翼弦0.18m） |
| アスペクト比 | 8.33 |
| 翼面荷重 | 1.56 kg/m²（15.6 g/dm²） |
| 失速速度 | 4.76 m/s（CLmax=1.10 前提） |
| 最良滑空 | L/D 14.5 ＠ 5.87 m/s、沈下率 0.405 m/s |
| 最小沈下 | 約0.36 m/s ＠ 約4.9 m/s（失速直前域。理論最小沈下CL=1.25はCLmax超過のため到達不可——設計上の正直な限界として記録） |
| 水平尾翼容積 VH | 0.60（標準域 0.4–0.6 の上限） |
| 垂直尾翼容積 VV | 0.040（標準域 0.02–0.05） |

## 3. 前提（仮定値——実測で置き換える対象）
- CD0 = 0.025（模型グライダーの標準域 0.02–0.03 の中値）
- Oswald効率 e = 0.80（標準域 0.75–0.85）
- CLmax = 1.10（低レイノルズ数での Clark Y 級翼型）
- 尾翼腕 0.65 m（全長 約0.95 m 想定）
